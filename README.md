# 💱 Currency Converter

A simple and user-friendly **Currency Converter** application that allows users to convert amounts from one currency to another. It helps users understand currency values and exchange rates through an easy-to-use interface.

## ✨ Features

- 💰 **Currency Conversion:** Convert amounts between different currencies.
- 🌍 **Multiple Currencies:** Select currencies for conversion.
- 📊 **Exchange Rates:** Get exchange rates to calculate converted amounts.
- ⚡ **Fast Conversion:** Quickly calculate currency values.
- 🎨 **User-Friendly Interface:** Simple and interactive design.
- 📱 **Responsive Design:** Easy to use across different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and user interface.
- **JavaScript** – Conversion logic and interactive functionality.
- **Currency Exchange API** – Exchange rate data (if configured in the project).

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/Kshitija20022006/currency-converter.git
```

### 2. Navigate to the Project Folder

```bash
cd currency-converter
```

### 3. Run the Application

Open the `index.html` file in your browser.

You can also use the Live Server extension in Visual Studio Code.

## 🎯 How to Use

1. Open the Currency Converter application.
2. Enter the amount you want to convert.
3. Select the source currency.
4. Select the target currency.
5. Click the Convert button.
6. View the converted amount.
